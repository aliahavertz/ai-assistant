
# AI Assistant

An AI-powered web application built using React and Python.

## Project Description

This project aims to develop an AI-powered web application
that allows users to interact with an AI assistant.

## Technologies Used

### Frontend
- React
- TypeScript
- Vite

### Backend
- Python
- FastAPI

### Database
- PostgreSQL

### AI Integration
- Google Gemini API

## Project Features

- AI Chatbot
- User Authentication
- Conversation History
- Dashboard
- AI-powered Responses
